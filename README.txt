PAKET MONALISA - WEBSITE KATALOG

Isi:
- index.html       halaman utama
- styles.css       desain/responsive
- app.js           katalog, pencarian, filter, PDF viewer, WhatsApp
- assets/          ilustrasi kategori
- PAKET HARIAN 2027.pdf
- PAKET MINGGUAN 2027.pdf

Catatan:
1. Data produk dan harga diambil dari dua PDF yang diberikan.
2. "Harga 300 Hari" mengikuti brosur PAKET 300 HARI.
3. "Harga Mingguan" mengikuti brosur PAKET MINGGUAN.
4. "Estimasi 30 hari" dihitung dari harga 300 hari x 30; ini bukan angka yang tertulis langsung di brosur.
5. Gambar produk menggunakan ilustrasi kategori. Jika ingin foto produk asli, ganti file SVG di folder assets atau ubah sumber gambar pada app.js.
6. Untuk mengaktifkan tombol WhatsApp, buka app.js lalu isi WHATSAPP_NUMBER, misalnya "6281234567890".
7. Website bisa dibuka dengan double-click index.html. Untuk hasil terbaik, jalankan melalui server lokal/static hosting.

Alamat yang ditampilkan mengikuti brosur: Blok B, Desa Rajagaluh Lor.
